# 人员目录与邮件语言

人员只需录入一次。确认人负责核实本人情况，收件人负责接收指定信件；同一个人可以承担两种用途。私人和公开规则可以选择同一批确认人，同一人同一轮只需确认一次。确认资格与私人收件资格分别设置；每封信发给该信指定的收件人。

人员资料里明确选择邮件语言：中文、英文或俄文。语言用于系统邮件和 PDF 标签，信件正文保留原文。修改语言后，保持管理页打开，让所需 PDF 重新准备；已完成的同一封信保留原投递回执，排版或语言调整只更新 PDF。

修改人员资料后，请在确认名单或公开邮件收件名单中分别选择其用途。确认规则仍由本人保存，并在下次本人签到时采用；正在进行的轮次继续使用冻结规则。

## 界面语言与未保存提示

侧栏和设置页的“界面语言”切换管理界面；人员资料里的“邮件语言”用于该人的系统邮件和 PDF 标签。两者分别保存，正文保持原文。

顶部只有实际存在未保存修改时才显示提示。点击后可返回相应页面，展开需要编辑的表单并定位到修改的控件；多个位置有修改时可以分别选择。定位用于继续编辑，保存仍由对应表单或草稿自动保存完成。

未发起保存时，将输入改回已保存的值会清除相应提示。保存请求失败或结果尚未确认时会保留输入和未保存状态。公开草稿自动保存成功后，即使尚未“应用”为正式版本，也属于已保存。规则保存后显示为待下次本人签到采用，保存状态已经完成。

## 从旧目录升级

schema 23 用人员映射连接原联系人和私人收件人。原有 ID、私人信件关联、历史回执和冻结规则原样保留。人员匹配使用规范化邮箱。

如果旧两侧已有不同的名字、语言或启停状态，迁移保留原值。明确编辑相应字段后才同步两种用途；每次保存只同步明确编辑的字段，其余差异保留。更换邮箱或停用会使该人的旧核验入口失效。

只存在一侧的旧人员会补齐另一个用途的资料。实际确认与公开投递名单继续使用原有选择；请在相应名单中明确调整其用途。

## 备份与恢复

新完整备份为 schema 24，包含人员映射、原联系人和收件人。恢复校验映射是否一一对应、引用是否完整、邮箱是否匹配；缺少或损坏的映射会拒绝恢复。恢复时会清除中断编辑留下的临时写入标记。

离线工具仍接受 schema 16–23 旧备份；schema 16–22 载入原数据后再补齐统一目录，保留旧 ID 和已有字段值。恢复保持释放暂停、保留真实本人签到时间、建立新轮次并使旧访问和核验链接失效。详见 [运维与恢复](OPERATIONS.md)。
